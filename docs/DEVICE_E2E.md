# DEVICE_E2E — 二元驗證紀錄（Batch V ＋ 各 batch E2E 判定）

規則（照 ROADMAP Batch V）：
- 每個 check 只有 **pass / fail**（數值型附量測值）。禁止自由文字觀察。
- 任何 check 沒有判定值＝該 batch 未完成。fail 不當場修，各開一個 worklist 條目。
- **用詞界線**：V-phone 未補齊前，所有功能只得宣稱「桌機已驗證」，不得宣稱
  「手機端已驗證」。
